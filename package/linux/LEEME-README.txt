PLANET HARRIERS - RECOMP (Linux x86_64 / Steam Deck, SDL2 + Vulkan)
===================================================================
Pocket_lucho + Claude.  https://github.com/PocketLucho/Planet-Harriers---Recompilation  (GPL v2)

ES  1. Copia pharrier.zip en "roms".
    2. Ejecuta una vez ./build_game.sh (necesita cc y make: sudo apt install build-essential;
       en Steam Deck usa una distrobox o compila en otro PC Linux y copia libph_game.so).
    3. ./pharrier   (F10 o L3+R3: opciones; necesita libSDL2 y un driver Vulkan)
    Sin el paso 2 funciona con el interprete (mas lento). libph_game.so sale de TU ROM: no lo distribuyas.

EN  1. Copy pharrier.zip to "roms".
    2. Run ./build_game.sh once (needs cc and make: sudo apt install build-essential; on a Steam
       Deck use a distrobox, or build on another Linux PC and copy libph_game.so).
    3. ./pharrier   (F10 or L3+R3: options; needs libSDL2 and a Vulkan driver)
    Without step 2 it runs on the interpreter (slower). libph_game.so comes from YOUR ROM: do not distribute it.

Teclas / keys: 5 coin, 1 start, arrows stick, Z shot, X missile, C bomb, A/S view change,
F2 test, F1 service, P pause, F11 fullscreen, F12 screenshot, Esc quit.
